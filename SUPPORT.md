# Support

## Documentation

For installation, configuration, concepts, tutorials, and operational guidance,
visit the
[Orchestrator documentation](https://docs.reimaginate.online/orchestrator).

## Paid support

Orchestrator support, configuration assistance, and defect triage are available
through Reimaginate's paid support channels. Customers should email
[support@reimaginate.online](mailto:support@reimaginate.online) using the
support arrangements provided by their Reimaginate agreement.

Include the organisation and applicable support agreement, Orchestrator
version, affected package or component, minimal reproduction steps, expected
and actual behaviour, and relevant logs with credentials, tokens, and customer
data removed.

This repository does not provide support or defect triage through GitHub Issues
or Discussions.

Report suspected vulnerabilities privately by following
[SECURITY.md](SECURITY.md).
