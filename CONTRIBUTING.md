# Contribution policy

## No external contributions

This repository is a generated public snapshot of Orchestrator's private source
repository. It is provided for source access and transparency, not as the
authoritative development repository.

Reimaginate does not accept external contributions to this repository,
including source code, documentation, patches, pull requests, or other proposed
repository changes.

## Defect reports

Customers may report reproducible source defects through Reimaginate's paid
support channel at
[support@reimaginate.online](mailto:support@reimaginate.online). Describe the
problem, expected behaviour, and reproduction steps without submitting a
patch. Support reports are not contributions.

Reimaginate may independently address reported defects in the private source
repository and include the resulting changes in a later public snapshot.

Follow [SECURITY.md](SECURITY.md) instead of opening a public issue for a
suspected vulnerability.
