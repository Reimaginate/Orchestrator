# Security policy

## Supported versions

Security fixes are applied to the latest supported Orchestrator release unless
Reimaginate states otherwise.

## Reporting a vulnerability

Do not report suspected vulnerabilities through public GitHub issues,
discussions, or pull requests.

Use
[GitHub private vulnerability reporting](https://github.com/Reimaginate/Orchestrator/security/advisories/new)
to send the report privately to the repository maintainers. Include:

- the affected Orchestrator version and component;
- the potential impact;
- clear reproduction steps or a minimal proof of concept; and
- any suggested mitigation, if known.

Do not include customer data, credentials, access tokens, or other secrets.
Reimaginate will assess the report and coordinate appropriate next steps
through the private report.
