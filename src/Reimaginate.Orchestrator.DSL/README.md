# Reimaginate.Orchestrator.DSL

Orchestrator is Reimaginate's opinionated YAML workflow and durability layer built on the [Microsoft Agent Framework Workflows runtime](https://github.com/microsoft/agent-framework).

YAML DSL parsing and validation support for Orchestrator workflow definitions.

This package contains the models and parsing infrastructure used to turn `.workflow.yaml` files into Orchestrator workflow definitions that the runtime materializes as Microsoft Agent Framework workflow graphs.
